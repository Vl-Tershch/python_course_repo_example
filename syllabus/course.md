# Программирование на Python

## Цель

Сформировать глубокое понимание базовой модели языка Python и практические навыки разработки надежных программ: от типов, функций и структур данных до управления памятью, ООП, файлов, тестирования и организации проекта.

## Результаты обучения

Студент умеет:

- [x] объяснять модель объектов, ссылок и изменяемости;
- [x] использовать коллекции, функции и исключения;
- [x] проектировать небольшие объектно-ориентированные программы;
- [x] работать с файлами и структурированными данными;
- [x] писать тестируемый и читаемый Python-код.

## Оценивание

| Компонент | Вес |
|---|---:|
| 5 лабораторных | 50% |
| мини-контрольные | 20% |
| итоговый проект | 30% |

> [!IMPORTANT]
> Использование генеративного ИИ допустимо для объяснения ошибок и поиска альтернативных подходов. Студент должен уметь объяснить весь сданный код и указать существенную внешнюю помощь.
