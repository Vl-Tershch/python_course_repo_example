# Лабораторная 1. Обработка данных студентов

## Данные

Используйте набор прямо из задания:

```csv
student,group,score
Alice,P3110,89
Bob,P3110,73
Carol,P3120,95
Dave,P3120,67
Eve,P3110,91
```

## Нужно реализовать

- [ ] преобразование строк в структуру Python;
- [ ] средний балл по группе;
- [ ] список студентов выше заданного порога;
- [ ] студент с максимальным баллом;
- [ ] аккуратную обработку пустого набора.

## API решения

```python
def average_by_group(rows: list[dict]) -> dict[str, float]: ...
def top_students(rows: list[dict], threshold: int) -> list[str]: ...
```

| Вызов | Ожидаемый результат |
