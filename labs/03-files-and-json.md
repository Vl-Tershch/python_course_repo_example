# Лабораторная 3. Файлы и JSON

## Исходный JSON

```json
{
  "course": "Python",
  "students": [
    {"name": "Alice", "score": 89},
    {"name": "Carol", "score": 95}
  ]
}
```

## Реализуйте

1. Чтение JSON из файла.
2. Валидацию обязательных ключей.
3. Формирование текстового отчета.
4. Запись результата в новый файл.
5. Обработку `FileNotFoundError` и некорректного JSON.

> [!CAUTION]
> Не ловите `Exception` без необходимости: это скрывает реальные ошибки программы.
