## Логика курса

```mermaid
flowchart LR
    A[Синтаксис и типы] --> B[Коллекции]
    B --> C[Функции]
    C --> D[Память и модель объектов]
    D --> E[ООП]
    E --> F[Исключения и файлы]
    F --> G[Итераторы и генераторы]
    G --> H[Модули и окружение]
    H --> I[Тестирование]
    I --> J[Итоговый проект]
```
