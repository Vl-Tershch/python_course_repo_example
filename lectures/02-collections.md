# Лекция 2. Коллекции

## Выбор структуры

| Структура | Сохраняет порядок | Изменяема | Быстрый поиск по ключу |
|---|---|---|---|
| `list` | да | да | нет |
| `tuple` | да | нет | нет |
| `set` | нет* | да | да |
| `dict` | да | да | да |

`*` Не следует использовать порядок множества как часть логики программы.
